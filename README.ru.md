# AlmaZoom · цифровой зум до 1000×

**[Скачать APK AlmaZoom 1.1.2](https://github.com/zz5644934-design/almazoom-x1000/releases/download/v1.1.2/AlmaZoom-v1.1.2.apk)** · [English](README.md)

Нужен Samsung Galaxy с root и настроенным Vector.

Модуль для [Vector](https://github.com/JingMatrix/Vector), который расширяет шкалу цифрового зума в штатной камере Samsung до 1000×. Работает в режиме «Фото» с задней камерой и JPEG.

После штатного предела AlmaZoom увеличивает центр превью. При съёмке Samsung делает и обрабатывает обычный снимок на максимальном для выбранного режима зуме. Модуль затем кадрирует готовый JPEG с тем же коэффициентом, прежде чем камера передаст снимок галерее. Например, при выборе 400× поверх штатных 100× модуль берёт центральную четверть кадра по ширине и высоте. Длинная сторона итогового JPEG ограничена 2048 пикселями. Цифровое увеличение само по себе не добавляет деталей.

Совместимость зависит от внутренних классов Samsung Camera, в том числе после обновлений на той же модели. В 1.1.2 модуль подбирает длину добавленной шкалы по фактическому пределу камеры. Математика шкалы проверена для пределов 10×, 20×, 30×, 50× и 100×. Для расширения шкалы нужны подходящие хуки сохранения JPEG и совместимый вид превью.

## Установка

1. Установи APK AlmaZoom как обычное приложение.
2. В Vector включи AlmaZoom и выбери **Камера Samsung** (`com.sec.android.app.camera`) в области действия модуля.
3. Полностью закрой камеру и открой её снова. В режиме «Фото» выбери заднюю камеру и обычный режим JPEG, например 12 Мп.
4. Открой шкалу зума и прокрути дальше штатного предела. Переключатель расширения находится в панели быстрых настроек камеры.

## Сборка

Нужны JDK 17 и Android SDK Platform 35. Gradle Wrapper загрузит Gradle 8.9 и проверит контрольную сумму дистрибутива.

```sh
./gradlew :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`. На Windows команда запускается через `gradlew.bat`. Для обновления поверх ранее установленного APK сертификат подписи должен совпадать.

## Проверка новой модели

Для проверки камеры достаточно снять один неподвижный объект со штатным максимумом и с удвоенным значением на шкале AlmaZoom. Во втором JPEG тот же объект должен занимать примерно вдвое больше места по ширине и высоте. Укажи модель, версию Android, точную версию Samsung Camera и строки Vector с префиксом `AlmaZoom`.

`CAMERA_PROFILE_UNAVAILABLE` означает, что хуки камеры этой сборки не совпали с профилем модуля. `CROPPED_BEFORE_PUBLICATION` означает, что кадрирование прошло. Для маршрута Samsung `SAMSUNG_SCAN_RETURNED uriPresent=true` означает, что сканер вернул ссылку на финальный файл.
